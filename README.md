# Mentoria — Marketing, Vendas e IA

Página de venda da mentoria (do zero ao 10K/mês prestando serviços de marketing e IA).
Site estático, arquivo único `index.html` + imagens.

## Ver localmente
Dê dois cliques em `index.html`, ou rode:
```bash
python3 -m http.server 4321
# http://localhost:4321/
```

## Onde editar (no index.html)
- **WhatsApp:** `const WHATSAPP`
- **Captura de leads:** `const LEADS_ENDPOINT` (origem "Mentoria")
- **Preço:** seção `#preco`
- **Foto do mentor:** `mentor.jpg`
- **Prints de receita:** `receita-1..3.png`
- **Resultados de clientes:** `resultado-1..6.jpg`
